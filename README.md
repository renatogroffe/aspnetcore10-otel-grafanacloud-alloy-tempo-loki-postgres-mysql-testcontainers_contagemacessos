# aspnetcore10-otel-grafanacloud-alloy-tempo-loki-postgres-mysql-testcontainers_contagemacessos
Exemplo de uso de OpenTelemetry + Grafana Cloud + Alloy (collector) + Tempo (trace) + Loki (logs) em uma API REST de contagem de acessos baseada em .NET 10 + ASP.NET Core e que utiliza bases de dados PostgreSQL + MySql + Testcontainers.
